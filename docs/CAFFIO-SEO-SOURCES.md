# Caffio SEO and Social Metadata Sources

This note records the external references consulted while implementing Caffio social previews and page descriptions.

| Source | Used for |
|---|---|
| [Open Graph protocol](https://ogp.me/) | Required `og:title`, `og:type`, `og:image`, and `og:url`; recommended description, locale, site name, and image alt/structured properties. |
| [Google Search Central — Control your snippets](https://developers.google.com/search/docs/appearance/snippet) | Unique, page-specific descriptions that summarize the actual product content rather than a keyword string. |
| [Google Search Central — Meta tags and attributes](https://developers.google.com/search/docs/crawling-indexing/special-tags) | Supported description/meta behavior and the caution that JavaScript-injected metadata should be tested carefully. |

## Content boundary

The keyword set in the Case Study is a planning vocabulary, not a claim of measured search volume or ranking. Validate it with first-party Search Console data and the target market before treating any term as high-value.
