# MIZAN COFFEE — Connector and Access Policy

## الحالة الحالية

المشروع واجهة ثابتة، ولا يستطيع كود الواجهة الوصول مباشرة إلى اتصالات المستخدم أو أدواته. الاتصالات التالية متاحة في سياق العمل الحالي فقط، وليست أسرارًا أو واجهات متاحة للمتصفح:

| الاتصال | الحالة الحالية | الاستخدام المقصود | السياسة |
|---|---|---|---|
| GitHub | مفعّل | إدارة المستودعات والمراجعة والتعاون البرمجي | يُستخدم لمهام الكود والمراجعة فقط، ولا تُرفع أسرار أو بيانات عملاء |
| Gmail | مفعّل بحساب معروف | قراءة أو صياغة مراسلات عند طلب المستخدم | لا إرسال أو نشر أو حذف دون تأكيد صريح قبل الفعل الخارجي |
| Google Workspace | مفعّل بحساب معروف | البحث في الملفات والمستندات المرجعية | تُستخدم الملفات ذات الصلة فقط، ولا تُنسخ بيانات شخصية إلى المستودع |
| Make | مفعّل | تشغيل سيناريوهات أتمتة جاهزة عند طلب واضح | لا يُشغّل سيناريو يكتب أو يرسل أو ينشر خارجًا دون عرض أثره وطلب التأكيد |
| Zapier | مفعّل | تشغيل أتمتة جاهزة عند طلب واضح | نفس سياسة Make، مع أقل صلاحية وعدم إنشاء مسارات جديدة بالتخمين |

## قرار التهيئة

لا تُفعّل اتصالات إضافية تلقائيًا؛ لا توجد حاجة حالية إلى متجر أو CRM أو تحليلات إعلانية كي تعمل الواجهة المنشورة. إذا أصبح الهدف قبول الطلبات الحقيقية، يكون القرار المفضل هو اعتماد منصة تجارة متكاملة ثم توثيق مصدر البيانات وحالات المخزون والدفع قبل ربط الواجهة.

## ضوابط الأمان

لا توضع مفاتيح أو رموز وصول في ملفات الواجهة أو في مستودع GitHub أو في ملفات الأصول المشتركة. أي تكامل جديد يجب أن يمر عبر مصدره الرسمي، ويحدد طريقة المصادقة، وفحصًا صحيًا، والعمليات الأساسية، وحدود الصلاحيات، وآلية الإيقاف أو التدوير.
