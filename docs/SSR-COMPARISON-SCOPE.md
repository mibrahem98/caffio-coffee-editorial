# نطاق العرض الخادمي لمقارنة Caffio

تطبّق هذه النسخة عرضًا خادميًا **لمسارات المقارنة فقط** من أجل أن تحصل منصات المشاركة والزواحف على عنوان ووصف وcanonical وOpen Graph وTwitter Card وصورة PNG مخصصة قبل تشغيل JavaScript. كما يضيف الخادم ملخصًا قصيرًا مقيدًا بالدليل داخل HTML الأولي لمسار `/compare`.

لا يحوّل هذا التنفيذ كل واجهات Caffio التفاعلية إلى React SSR كاملًا؛ تبقى الصفحة التفاعلية مرسومة من العميل بعد التحميل. يعد تحويل جميع المسارات العامة إلى SSR كاملًا توسعًا منفصلًا يتطلب معالجة شاملة لحالات التخزين المحلي والترطيب لكل صفحة.

لا تقبل مسارات `/compare/og.png` و`/compare/pdf` سوى معرفي منتجين مختلفين موجودين في الكتالوج. تعرض البيانات المنشأ والتذوق بصيغتها الموثقة أو المعلقة الحالية فقط، ولا تنشئ ادعاءات منشأ أو دفعة أو تذوق جديدة.
