# Caffio Coffee — دليل تسليم المشتري

## ما الذي يُسلَّم

| المجال | المحتوى | موضعه في المشروع |
|---|---|---|
| واجهة العلامة | الصفحة الرئيسية، التصميم المتجاوب، الوضعان اللونيان، RTL/LTR، والتنقل | `client/src/pages/` و`client/src/components/` و`client/src/index.css` |
| نموذج المحتوى | منتجات ثنائية اللغة، حالات دفعات، ووصفات ملاحظات الحقل | `client/src/lib/mizanCatalog.ts` |
| التفاعل المحلي | سلة تجريبية، عروض، مقارنة، مفضلة، سجل بحث، طلبات واشتراكات تجريبية | `client/src/contexts/` و`client/src/lib/` |
| طبقة الخادم | وسوم مشاركة ومسارات PDF ومراجعة انعكاسات التذوق | `server/` |
| الثقة والحوكمة | بروتوكول المصادر، سياسة المحتوى، وحالات pending | `docs/RESEARCH-SOURCES.md` و`docs/CONTENT-DATA-CONTRACT.md` |
| الجودة | اختبارات وحدة، اختبارات متصفح، فحص TypeScript، وبناء إنتاج | `client/src/lib/*.test.ts` و`server/*.test.ts` و`e2e/` |

## خطوات الاستلام

| الترتيب | الإجراء |
|---|---|
| 1 | استنسخ المستودع وثبّت الحزم بـ `pnpm install`. |
| 2 | أضف متغيرات المنصة/قاعدة البيانات في إعدادات البيئة فقط؛ لا تُسلّم أو تُنشئ ملف أسرار في المستودع. |
| 3 | شغّل `pnpm test` و`pnpm run test:e2e` و`pnpm run check` و`pnpm run build`. |
| 4 | راجع `docs/RESEARCH-SOURCES.md` قبل تحويل أي حالة معلقة إلى ادعاء منشأ أو تذوق. |
| 5 | أبقِ التجارة والاشتراك في وضع التجربة إلى أن يُنفذ Checkout وwebhook وشحن حقيقيان من جهة الخادم. |

## ما لا يدخل ضمن الوعد التجاري الحالي

لا تتضمن الحزمة إثبات إيراد أو قاعدة عملاء أو علامة مسجلة أو مخزونًا أو بوابة دفع حية أو شحنًا حقيقيًا أو CRM أو بيانات دفعات/تذوق موثقة. كما لا يجب نقل جلسات مستخدمين أو أسرار أو أي حق لصورة/خط/اسم لا يملك البائع حق نقله صراحةً.

## فحص قبول المشتري

قبل الإغلاق، يراجع المشتري رابط المعاينة، شاشات الهاتف، التبديل العربي/الإنجليزي، التباين، لوحة إدارة التعليقات باستخدام حساب مخول، مسارات مشاركة المنتجات والمقارنة، واستجابة حالات البيانات الفارغة. ويجب إرفاق ترخيص بيع يحدد نطاق الاستخدام، التحديثات، الدعم، وحقوق الأصول بصورة مستقلة عن هذا الدليل.
