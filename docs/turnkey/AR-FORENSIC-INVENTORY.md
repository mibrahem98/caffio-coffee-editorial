# جرد المسارات والأدوات ونقاط الإدخال — Caffio / MIZAN

**تاريخ الجرد:** 18 أغسطس 2026  
**حالة النطاق:** واجهة عامة ثنائية اللغة مع محاكاة تجارة محلية؛ لا تعديل خادمي أو قاعدة بيانات أو API ضمن هذه الجولة.

## المسارات العامة ومسارات الاسترداد

| المسار | الوظيفة الظاهرة | حدود/حالة الفحص المخططة |
|---|---|---|
| `/` | القصة، المجموعة، البحث الخفيف، FAQ، السلة، قائمة الانتظار، الوضع/اللغة | اختبار التنقل واللغة والسمات والنماذج ومحاكاة السلة. |
| `/coffee/:id` | سجل منتج ومشاركة ودفعة وانعكاسات | اختبار ID صالح/مفقود، مشاركة، وحالات pending/فارغ. |
| `/search` | بحث، URL params، مرشحات، ترتيب، سجل وتفضيلات محلية | أعلى أولوية لإدخال URL والتخزين المحلي والحالات الفارغة. |
| `/compare` | زوج سجلات، مشاركة، وصفات، تصدير | اختبار زوج صالح ومكرر ومفقود وتصدير دون نقل بيانات لطرف ثالث. |
| `/notes` و`/case-study` و`/sources` | محتوى تحريري ومصادر | اختبار اللغة، الروابط، وعودة التنقل. |
| `/favorites` و`/profile` و`/track` | محفوظات ومتطلبات محلية ومحاكاة الطلب | اختبار حدود التخزين المحلي والحالات الفارغة ومسح البيانات. |
| `/society` و`/payments` | محاكاة اشتراك/نشاط دفع | اختبار الوضوح: لا دفع ولا شحن ولا سجل مزود حي. |
| `/admin/tasting` | بوابة إدارة الانعكاسات | اختبار بوابة واجهة المستخدم فقط؛ مراجعة إجراءات الخادم توثق كحد خارج التعديل. |
| `/404` وأي مسار غير معروف | استرداد آمن | اختبار وجود route fallback وعودة إلى المسارات العامة. |

## عناصر الحالة والمدخلات

| السطح | أنواع الإدخال | الحدود المراد التحقق منها |
|---|---|---|
| السلة | كود خصم، أزرار كمية، إنشاء طلب محلي | كود خاطئ، كمية سالبة/صفرية، عناصر مفقودة، عدم إنشاء طلب حي. |
| البحث | query-string، نص، roast، brew، tasting، سعر، ترتيب | قيمة URL غير معروفة، JSON محلي تالف، نتائج صفرية، مسح تفضيلات دون مسح الاستعلام. |
| المقارنة | `a`/`b` من URL، مشاركة، SVG/PDF | معرف مفقود أو مكرر، نسخة الحافظة الفاشلة، عرض pending. |
| Society | اختيارات select وخطوات محاكاة | انتقالات خطوة غير صالحة، استرداد الخطوة، عدم تخزين عنوان أو بطاقة أو بريد. |
| الانعكاسات | تقييم وتعليق محدودان | طول التعليق، حالة الدخول، حالة pending، وحجب المحتوى غير المعتمد. |
| FAQ ومساعد القهوة ودليل التحضير | نص، combobox/select، أزرار تقدم | لوحة المفاتيح، عدم وجود نتائج، اختيار صالح فقط من السجل. |
| اللغة والسمات | select وزر، تفضيلات جهاز/متصفح | fallback عربي/إنجليزي، `dir`/`lang`، استمرار صحيح، تقليل الحركة. |

## مفاتيح تخزين المتصفح المكتشفة

تتضمن المفاتيح المحلية: `mizan-theme`، `mizan-lang`، `mizan-cart`، `mizan-demo-orders`، `mizan-demo-order`، `mizan-favorites`، `caffio-society-demo`، سجل البحث وتفضيلات المرشح، بالإضافة إلى مفتاح داخلي لمعلومات مصادقة وقت التشغيل. ينبغي ألا تُخزن هذه المفاتيح أسرارًا أو بطاقات أو عناوين أو أرقام تتبع حقيقية؛ وسيختبر التدقيق JSON التالف والحدود النوعية وآثار الكتابة في دورة العرض.

## مؤشرات أولية مثبتة قبل الاختبار

1. مسار `/manus-storage/*` رد بحالة `307` في الخادم العامل أثناء probe، لذا فإن `PathError` المقتصر على سجل سابق لا يُسجل عيبًا حيًا قبل إعادة إنتاجه.
2. خطاف المصادقة يكتب بيانات الاستعلام إلى `localStorage` داخل `useMemo` أثناء العرض. هذه كتابة جانبية غير لازمة في مرحلة render وستدخل فحص السبب الجذري.
3. حاجز الأخطاء العام يعرض `error.stack` للمستخدم. هذا تسريب محتمل لتفاصيل بيئة العميل ويحتاج قرار إصلاح واختبار واضحين.
