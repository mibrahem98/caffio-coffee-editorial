# MIZAN COFFEE — Content Data Contract

قبل إدراج أي قهوة في المجموعة، يجب أن تتوفر بطاقة مصدر داخلية تحتوي على الحقول التالية:

| الحقل | المطلوب | ملاحظات التحقق |
|---|---|---|
| الاسم التجاري | اسم واضح بالعربية والإنجليزية | لا يخلط بين اسم المنتج واسم الصنف |
| المنشأ | البلد والمنطقة عند توفر الدليل | لا تُضاف مزرعة أو إحداثيات بلا مصدر |
| الصنف | اسم الصنف كما في الوثيقة الأصلية | يُراجع مقابل مرجع الأصناف عند الحاجة |
| المعالجة | الوصف المعتمد من المنتج أو المورد | لا تُستنتج المعالجة من النكهة |
| الارتفاع | قيمة ووحدة قياس ومصدر | لا تُحوّل الوحدات دون حفظ القيمة الأصلية |
| ملف التحميص | وصف قابل للفهم لا ادعاء معياري | كلمة «فاتح/متوسط/داكن» تحتاج سياقًا واضحًا |
| ملاحظات التذوق | وصف تحريري غير منسوب لمستخدمين | تُصاغ كملامح متوقعة لا كضمان ذوقي |
| السعر والتوافر | حالة المنتج وتاريخها | لا يظهران كحقيقيين قبل ربط مصدر تجارة فعلي |
| المصدر | رابط أو ملف وتاريخ مراجعة | لا يكفي رابط عام لا يثبت الحقل نفسه |

تُرفض البطاقة إذا كان أي حقل أساسي مجرد تخمين أو إذا كان النص يوحي باعتماد أو مراجعة أو طلب حقيقي غير متاح. تُحفظ النسخة العربية والإنجليزية كمحتوى متكافئ، مع أولوية الوضوح على الترجمة الحرفية.
