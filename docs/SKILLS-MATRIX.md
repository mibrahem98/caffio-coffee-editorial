# MIZAN COFFEE — Capability Matrix

هذه المصفوفة تحوّل احتياجات المشروع إلى مهارات تشغيلية قابلة للتسليم، بدل تشغيل أدوات أو تكاملات لا يحتاجها المشروع.

| مجال العمل | متى يُستخدم | الناتج المطلوب | معيار الاكتمال |
|---|---|---|---|
| هندسة العلامة والواجهة | عند تعديل بنية الصفحة أو الهوية | قرار بصري موثق وتنفيذ متسق مع `ideas.md` | لا توجد ألوان أو خطوط أو مكونات خارج النظام دون مبرر موثق |
| البحث التحريري للقهوة | عند كتابة قصة منشأ أو معالجة أو صنف | بطاقة محتوى مرتبطة بمصدر وتاريخ مراجعة | كل ادعاء قابل للتتبع إلى دليل أولي أو مصدر رسمي |
| الترجمة العربية والإنجليزية | عند إضافة أو تعديل نصوص الواجهة | مفاتيح متطابقة للغتين ونص عربي محرر | لا توجد مفاتيح مفقودة، والاتجاه RTL/LTR سليم |
| الوصول والجودة | قبل كل إصدار وبعد التغييرات التفاعلية | تقرير فحص يدوي وآلي مختصر | لوحة المفاتيح، التركيز، التباين، النص البديل، وإعادة التدفق مجتازة |
| اختبار التفاعل | عند تعديل السلة أو النماذج أو التنقل | حالات نجاح وفشل موثقة | لا توجد أزرار صامتة أو مسارات توحي بعملية حقيقية غير متصلة |
| إدارة الأصول | عند إضافة صورة أو ملف تنزيل | أصل مضغوط ومسار تخزين دائم ووصف بديل | لا توجد أصول كبيرة محلية داخل حزمة النشر |
| إدارة التكاملات | عند الحاجة إلى CRM أو متجر أو نشر خارجي | قرار صلاحيات ومصفوفة وصول وموافقة صريحة | أقل صلاحية ممكنة، ولا توجد أسرار في الكود أو الملفات العامة |
| التشغيل المجدول | عند الحاجة إلى مراجعة دورية تحتاج حكمًا تحليليًا | تقرير مراجعة دوري داخل المهمة | لا يُستخدم التشغيل المجدول للفحص الدقيق المتكرر أو الأعمال الآلية البسيطة |

## مهارات ممنوعة الاستخدام غير المنضبط

لا تُستخدم أي قدرة لإنشاء شهادات أو مراجعات أو أرقام أداء غير موثقة. ولا تُفعّل خدمة نشر أو دفع أو إرسال بريد أو تعديل بيانات خارجية تلقائيًا؛ هذه أفعال منفصلة تتطلب تكاملًا واضحًا وموافقة مناسبة.
