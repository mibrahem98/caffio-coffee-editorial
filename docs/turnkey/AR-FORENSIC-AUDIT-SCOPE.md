# نطاق التدقيق الجنائي والإصلاح القائم على الأدلة — Caffio / MIZAN

**مرجع الطلب:** `pasted_content_3.txt`  
**نطاق المشروع المعتمد:** واجهة Caffio/MIZAN العامة الثنائية اللغة، مع كون التجارة والحسابات الظاهرة محاكاة محلية ما لم يوجد تكامل موثق.

> هذا التدقيق يتبع مبدأ **عدم التساهل مع العيوب القابلة لإعادة الإنتاج**، لكنه لا يدّعي أن منع العيب أو الاستغلال «مستحيل رياضيًا» أو أن النظام «آمن بنسبة 100%». الإثبات المقبول هو اختبار قابل للتكرار، ومراجعة كود محددة، وفحص إنتاج أو متصفح مسجل النتيجة.

## قواعد الحماية والمحتوى

يظل مصدر الحقائق عن المنتجات والدفعات محكومًا بسجل المصادر وحالات `pending` أو `verified`. لا يعالج أي إصلاح حالة نقص البيانات باختلاق منشأ أو تذوق أو مراجعة أو تقييم. كما تظل السلة، الخصم، قائمة الانتظار، الاشتراك، الشراء والتتبع مسارات محلية تجريبية بحدود مرئية.

## تعريف «الإصلاح الدائم» في هذا التدقيق

يُسمى الإصلاح دائمًا عمليًا عندما يحقق الشروط الأربعة الآتية: يزيل السبب المحدد بدل إخفاء الاستثناء؛ يستخدم حدودًا نوعية أو تحققًا هيكليًا عند الإدخال؛ يحافظ على حالة آمنة عند الخطأ؛ ويغطيه اختبار آلي يعيد إنتاج الفشل السابق أو يثبت الشرط الوقائي. لا يعني ذلك وعدًا مطلقًا ضد كل تغيير مستقبلي أو تهديد غير معلوم.

## مخرجات مخططة

سيُسلّم جرد مسارات وأدوات، وسجل نتائج قابل للتتبع، وإصلاحات مثبتة إن وجدت، ومصفوفة تحقق عربية/إنجليزية توضح السبب الجذري والإجراء والدليل والحدود المتبقية.
