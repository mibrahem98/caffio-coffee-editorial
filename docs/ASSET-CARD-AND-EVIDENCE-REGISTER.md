# 6. الأسئلة الخمسة

1. هل الأصل المقصود للبيع هو **الكود/القالب فقط** أم **منتج** أم **نشاط قائم**، وما مرحلة الإفصاح المطلوبة: Blind أم Named أم بعد NDA؟
2. ما العملة والجغرافيا وتاريخ القطع المطلوب اعتمادها، ومن هو حساب الوجهة أو الكيان الذي سيتسلم المستودع والاستضافة؟
3. هل توجد قائمة غير سرية بأسماء المتغيرات والحسابات التي تحتاج نقلًا أو تدويرًا، وما خطة استبدالها بعد التسليم؟
4. ما الأصول التي يملك البائع حق نقلها تحديدًا—الاسم/العلامة، الصور، الخطوط، الموسيقى، والنطاق—وهل توجد وثائق رخصة لكل منها؟
5. هل توجد تحليلات استخدام أو إيراد أو عملاء أو احتفاظ قابلة للمراجعة، أم نثبت صراحة أن الأصل **كود/واجهة بلا بيانات تشغيلية مقدمة**؟
