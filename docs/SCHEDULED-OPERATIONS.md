# MIZAN COFFEE — Scheduled Operations

## المبدأ

التشغيل المجدول مخصص للمراجعات الدورية التي تحتاج قراءة وسياقًا وحكمًا تحليليًا. لا يُستخدم للفحص كل دقيقة أو كل ساعة، ولا لمهام حتمية بسيطة يمكن تنفيذها داخل التطبيق دون جلسة تحليل كاملة.

## المهمة الدورية المعتمدة

| الحقل | القيمة |
|---|---|
| الاسم | MIZAN — Weekly Brand and Content Audit |
| التكرار | أسبوعيًا، يوم الاثنين الساعة 09:00 بتوقيت المهمة |
| النتيجة | تقرير داخل المهمة يلخص حالة المصادر، المحتوى، الترجمة، الروابط، حدود التجربة، والمهام التالية |
| الأثر الخارجي | لا إرسال، ولا نشر، ولا تعديل بيانات تلقائيًا |
| معيار التصعيد | أي ادعاء غير موثق، رابط مكسور، فرق بين اللغتين، أو إيحاء بعملية شراء حقيقية يُرفع كعنصر يحتاج قرارًا |

## قالب التقرير

يبدأ التقرير بملخص تنفيذي من فقرة قصيرة، ثم جدول بالحالات: **سليم، يحتاج مراجعة، محجوب**. لكل عنصر يحتاج مراجعة يُذكر الملف أو القسم، وصف المشكلة، المصدر المطلوب، وخطوة الإصلاح. لا تُنشأ مراجعات أو شهادات أو بيانات عملاء كحل تجريبي.

## حدود المهمة

تراجع المهمة `ideas.md` وملفات `docs/` ومفاتيح الترجمة ومحتوى الصفحة والروابط المعلنة. لا تغيّر الكود، ولا ترسل بريدًا، ولا تنشر منشورًا، ولا تنفذ دفعًا، ولا ترفع ملفًا خارجيًا تلقائيًا. أي تغيير تنفيذي يظل مهمة مستقلة بعد مراجعة التقرير.
